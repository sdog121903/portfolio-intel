# Theses: why you own each stock

One file per holding. The daily report checks each day's news against it; the weekly deep dive
rebuilds the facts from primary documents.

- **Why I own it** is yours. Write it in your own words, even two sentences. Nobody else edits it.
- **What must stay true** and **Invalidation triggers** turn your reasons into things that can be
  checked. The starting points in each file are suggestions to edit or delete.
- Everything else is filled and refreshed by the weekly deep dive, with sources.

Copy `TEMPLATE.md` when you add a new stock.
